# Ternloom Technologies website

Main company website for **Ternloom Technologies**, serving small businesses in Ottawa and across Canada.

Domain: **ternloom.com**. Proposed canonical origin: `https://ternloom.com`.

## Services

| Service | Purpose |
| --- | --- |
| Website Development | Professional business websites that help customers find and contact a business. |
| Custom Business Software | Software built around a business's own workflows. |
| Business Automation & Integrations | Connected tools and automated workflows that reduce repetitive work. |

Supporting capability: **cloud deployment and hosting with simple infrastructure and predictable running costs**. Exact hosting, maintenance and support scope is agreed per project.

## Current state

The Working Weave website design is approved, and its implementation plan is prepared. The separate configuration brief still awaits approval. No Astro application, dependencies or public website has been created in this repository. Development and build commands are not available yet.

The owner selected static Astro, following the existing Turnory and Wood Dust Creations architecture pattern, with original Working Weave branding. Cloudflare Pages, TypeScript and plain CSS are proposed configuration defaults. Implementation begins with the technical foundation before designed pages.
