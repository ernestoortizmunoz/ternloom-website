## Implemented local website

- Eight content routes: `/`, `/services/website-development/`, `/services/custom-business-software/`, `/services/business-automation-integrations/`, `/projects/`, `/about/`, `/contact/`, `/privacy/`; plus a designed `404.html` recovery page.
- Shared Working Weave theme, semantic shell, wrapping navigation, skip target, visible focus, licensed local DM Sans, original vector hero, accepted brand assets, meaningful screenshot alternatives/captions and reserved image dimensions. Essential content, questions, email/direct-form fallbacks and links are static HTML; the development toolbar is disabled. Contact-only Tally is the sole executable-script/third-party embed exception; no analytics or backend is included. The owner-approved static privacy notice is linked from contact and every footer.
- Static Astro 7.4.4, TypeScript 6.0.3 and `@astrojs/check` 0.9.12; Node 24.22.2 with npm 11.19.1. Exact pins and lockfile are committed. Canonical origin is `https://ternloom.com`, locale `en-CA`, trailing slashes and directory output. Development and preview bind to loopback.
- One public site configuration, shared service/project records and reusable components. Cloud delivery remains supporting capability. Selected projects preserve their technology-provider/own-product roles and evidence limits; potential deliverables are not represented as completed commissions.
- Every page has unique title/description, canonical, Open Graph/Twitter metadata and original 1200×630 social artwork based on the accepted mark and weave. Factual Organization/WebSite schema appears throughout; Service schema only on its matching service page, and BreadcrumbList only where breadcrumbs are visible. JSON-LD escapes HTML-sensitive characters. No invented address, ratings, offers or storefront metadata.
- Default builds are noindex, emit `robots.txt` with `Disallow: /` and emit no production sitemap. Explicit release requires configured email/form/positive integer retention, all global readiness flags, and every displayed project’s copy/image approval. Global flags cannot bypass unapproved project records. A ready release includes the form with production context and only canonical indexable content routes; preview notices, test context, 404 and setup pages are excluded from the applicable release surfaces. This local output policy does not settle individual search/training crawler access.
