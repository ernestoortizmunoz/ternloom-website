# Local font

`dm-sans-latin.woff2` is the DM Sans Latin variable font, self-hosted for this website. Its SIL Open Font License is included in `DM-Sans-OFL.txt`. The font and license were copied as generic licensed assets from the local Bonita Nights repository; builds have no dependency on that repository or any remote font service.

The accepted Ternloom wordmark uses Arial, independently of DM Sans.
